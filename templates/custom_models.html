Deployment Configuration

# Deployment configuration for custom model
apiVersion: v1
kind: Deployment
metadata:
  name: greenspace-custom-model
spec:
  replicas: 3
  selector:
    matchLabels:
      app: custom-model
  template:
    metadata:
      labels:
        app: custom-model
    spec:
      containers:
      - name: model-server
        image: greenspaceai/model-server:latest
        ports:
        - containerPort: 8080
        env:
        - name: MODEL_PATH
          value: /models/custom_model.onnx
        - name: GPU_ENABLED
          value: "true"
        resources:
          limits:
            nvidia.com/gpu: 1
            memory: 4Gi
          requests:
            memory: 2Gi
            cpu: 1

Best Practices for Custom Models

Quality Data Collection

Collect diverse, representative data covering all expected scenarios. Include edge cases and difficult examples in your training set.

Class Balance

Ensure balanced representation of all classes. Use techniques like oversampling, undersampling, or weighted loss functions for imbalance.

Rigorous Validation

Use multiple validation sets, cross-validation, and hold-out test sets. Validate on data from different sources and time periods.

Continuous Monitoring

Monitor model performance in production. Set up alerts for performance degradation and plan for regular model updates.
