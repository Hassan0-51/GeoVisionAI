Step 2: Data Preparation Guide

Prepare your satellite imagery for optimal analysis results

2.1 Supported File Formats

Format Extension Max Size Best For Notes
GeoTIFF .tif, .tiff 2 GB High-resolution analysis Preferred format, includes georeferencing
JPEG2000 .jp2, .j2k 1 GB Sentinel-2 imagery Good compression, preserves quality
PNG with GeoJSON .png + .geojson 500 MB Web maps, screenshots Separate georeferencing file required
Raw Images .jpg, .png 200 MB Quick tests, education Manual georeferencing needed

Important Requirements

Georeferencing

Images must have proper coordinate reference system (CRS). WGS84 (EPSG:4326) or UTM recommended.

Resolution

Optimal resolution: 0.5m to 30m per pixel. Higher resolutions require more processing time.

File Size

Maximum single file: 2GB. For larger areas, consider tiling or using our mosaic tool.

Spectral Bands

RGB (3 bands) minimum. Multispectral (4-13 bands) supported for advanced analysis.

2.2 Data Quality Check

Good Quality Example

  • Clear georeferencing metadata
  • Less than 20% cloud cover
  • Proper contrast and brightness
  • Standard projection (WGS84/UTM)

Poor Quality Example

  • Missing coordinate system
  • Heavy cloud cover (>50%)
  • Severe atmospheric distortion
  • Non-standard file format

2.3 Quick Data Preparation Script

Use this Python script to check and prepare your imagery:

# Quick data preparation script for GreenSpace AI
import rasterio
import numpy as np
from osgeo import gdal

def check_imagery_quality(file_path):
    """Check basic quality metrics for satellite imagery"""
    try:
        # Open the raster file
        with rasterio.open(file_path) as src:
            # Check CRS (Coordinate Reference System)
            crs = src.crs
            print(f"CRS: {crs}")
            
            # Check dimensions
            height, width = src.shape
            print(f"Dimensions: {width} x {height}")
            
            # Check resolution
            res_x, res_y = src.res
            print(f"Resolution: {res_x:.2f} x {res_y:.2f} units/pixel")
            
            # Read first band for quality check
            band1 = src.read(1)
            
            # Calculate basic statistics
            mean_val = np.mean(band1)
            std_val = np.std(band1)
            print(f"Mean pixel value: {mean_val:.2f}")
            print(f"Standard deviation: {std_val:.2f}")
            
            return True
            
    except Exception as e:
        print(f"Error reading file: {e}")
        return False

# Example usage
if __name__ == "__main__":
    file_path = "your_satellite_image.tif"
    if check_imagery_quality(file_path):
        print("✓ File is ready for GreenSpace AI analysis")
    else:
        print("✗ File needs preparation before upload")

3.4 API Integration Example

For programmatic access, use our REST API:

# Python example: Upload and process via API
import requests
import time

API_KEY = "your_api_key_here"
BASE_URL = "https://api.greenspaceai.com/v1"

def upload_and_analyze(image_path, analysis_type="landcover"):
    # Step 1: Upload image
    headers = {"Authorization": f"Bearer {API_KEY}"}
    
    with open(image_path, 'rb') as f:
        files = {'file': f}
        upload_response = requests.post(
            f"{BASE_URL}/upload",
            headers=headers,
            files=files
        )
    
    if upload_response.status_code != 200:
        raise Exception(f"Upload failed: {upload_response.json()}")
    
    file_id = upload_response.json()['file_id']
    print(f"✓ Upload successful. File ID: {file_id}")
    
    # Step 2: Start analysis
    analysis_payload = {
        "file_id": file_id,
        "analysis_type": analysis_type,
        "parameters": {
            "model": "unet_plus",
            "detail_level": "balanced"
        }
    }
    
    analysis_response = requests.post(
        f"{BASE_URL}/analysis",
        headers=headers,
        json=analysis_payload
    )
    
    analysis_id = analysis_response.json()['analysis_id']
    print(f"✓ Analysis started. Analysis ID: {analysis_id}")
    
    # Step 3: Poll for results
    while True:
        status_response = requests.get(
            f"{BASE_URL}/analysis/{analysis_id}/status",
            headers=headers
        )
        
        status = status_response.json()['status']
        progress = status_response.json().get('progress', 0)
        
        print(f"Progress: {progress}% - Status: {status}")
        
        if status == "completed":
            break
        elif status == "failed":
            raise Exception("Analysis failed")
        
        time.sleep(10)  # Wait 10 seconds before polling again
    
    # Step 4: Get results
    results_response = requests.get(
        f"{BASE_URL}/analysis/{analysis_id}/results",
        headers=headers
    )
    
    return results_response.json()

# Run analysis
results = upload_and_analyze("satellite_image.tif")
print("✓ Analysis complete!")
print(f"Results URL: {results['download_url']}")

4.4 Common Interpretation Pitfalls

Important Considerations

Seasonal Variations

Vegetation classification accuracy varies by season. Summer imagery shows different results than winter.

Mixed Pixels

At lower resolutions, single pixels may contain multiple land cover types, reducing accuracy.

Cloud Shadows

Cloud shadows may be misclassified as water. Always check cloud cover percentages.

5.2 API Export Example

Programmatically export results using our API:

# Python: Export analysis results in multiple formats
import requests
import json

def export_analysis_results(analysis_id, formats=["geojson", "csv"]):
    API_KEY = "your_api_key_here"
    BASE_URL = "https://api.greenspaceai.com/v1"
    
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json"
    }
    
    # Request export in specified formats
    export_payload = {
        "analysis_id": analysis_id,
        "formats": formats,
        "include_metadata": True,
        "compression": "zip"
    }
    
    response = requests.post(
        f"{BASE_URL}/export",
        headers=headers,
        json=export_payload
    )
    
    if response.status_code == 202:
        export_job = response.json()
        job_id = export_job['job_id']
        print(f"✓ Export job created. Job ID: {job_id}")
        
        # Poll for completion
        while True:
            status_response = requests.get(
                f"{BASE_URL}/export/{job_id}/status",
                headers=headers
            )
            
            status = status_response.json()['status']
            print(f"Export status: {status}")
            
            if status == "completed":
                download_url = status_response.json()['download_url']
                print(f"✓ Export ready: {download_url}")
                
                # Download the file
                download_response = requests.get(download_url)
                with open("analysis_export.zip", 'wb') as f:
                    f.write(download_response.content)
                
                print("✓ Export downloaded successfully!")
                return True
                
            elif status == "failed":
                print("✗ Export failed")
                return False
            
            # Wait before polling again
            time.sleep(5)
    
    else:
        print(f"✗ Export request failed: {response.text}")
        return False

# Example usage
analysis_id = "analysis_12345"
export_analysis_results(analysis_id, formats=["geojson", "csv", "png"])
