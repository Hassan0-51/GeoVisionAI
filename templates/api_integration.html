API Integration Tutorial

Complete guide to integrating GreenSpace AI into your applications and workflows

Advanced Level | 45-60 minutes

API Overview

The GreenSpace AI REST API provides programmatic access to all platform capabilities, enabling you to integrate satellite imagery analysis directly into your applications, automate workflows, and build custom solutions.

POST

Upload & Analyze

/v1/analysis

Upload satellite imagery and start AI analysis. Supports multiple image formats and analysis types.

Parameters:
• image (file)
• analysis_type (string)
• parameters (object)
GET

Get Results

/v1/analysis/{id}/results

Retrieve analysis results including classification maps, statistics, and confidence layers.

Response Includes:
• Download URLs
• Statistics JSON
• Metadata
POST

Export Results

/v1/export

Export analysis results in various GIS formats (Shapefile, GeoJSON, KML, GeoTIFF).

Export Formats:
• Shapefile
• GeoJSON
• GeoTIFF
• KML/KMZ
GET

Status Check

/v1/analysis/{id}/status

Check analysis processing status and progress percentage.

Status Values:
• pending
• processing
• completed
• failed
GET

List Analyses

/v1/analyses

List all analyses for the authenticated user with pagination and filtering.

Query Parameters:
• limit (integer)
• offset (integer)
• status (string)
POST

Batch Processing

/v1/batch

Process multiple images in a single request with parallel processing.

Features:
• Parallel processing
• Progress tracking
• Error handling

Authentication & API Keys

API Key Authentication

All API requests require authentication using your API key. Include it in the Authorization header of every request.

Header Authentication

Include your API key in the Authorization header:

Authorization: Bearer your_api_key_here

Key Security

Best practices for API key security:

  • Store keys in environment variables
  • Never commit keys to version control
  • Use different keys for different environments
  • Rotate keys regularly

# Python: Upload satellite image and run analysis
import requests
import time

API_KEY = "your_api_key_here"
BASE_URL = "https://api.greenspaceai.com/v1"

def upload_and_analyze(image_path, analysis_type="landcover"):
    # Step 1: Upload image
    headers = {"Authorization": f"Bearer {API_KEY}"}
    
    with open(image_path, 'rb') as f:
        files = {'file': f}
        upload_response = requests.post(
            f"{BASE_URL}/upload",
            headers=headers,
            files=files
        )
    
    if upload_response.status_code != 200:
        raise Exception(f"Upload failed: {upload_response.json()}")
    
    file_id = upload_response.json()['file_id']
    print(f"✓ Upload successful. File ID: {file_id}")
    
    # Step 2: Start analysis
    analysis_payload = {
        "file_id": file_id,
        "analysis_type": analysis_type,
        "parameters": {
            "model": "unet_plus",
            "detail_level": "balanced"
        }
    }
    
    analysis_response = requests.post(
        f"{BASE_URL}/analysis",
        headers=headers,
        json=analysis_payload
    )
    
    analysis_id = analysis_response.json()['analysis_id']
    print(f"✓ Analysis started. Analysis ID: {analysis_id}")
    
    # Step 3: Poll for results
    while True:
        status_response = requests.get(
            f"{BASE_URL}/analysis/{analysis_id}/status",
            headers=headers
        )
        
        status = status_response.json()['status']
        progress = status_response.json().get('progress', 0)
        
        print(f"Progress: {progress}% - Status: {status}")
        
        if status == "completed":
            break
        elif status == "failed":
            raise Exception("Analysis failed")
        
        time.sleep(10)  # Wait 10 seconds before polling again
    
    # Step 4: Get results
    results_response = requests.get(
        f"{BASE_URL}/analysis/{analysis_id}/results",
        headers=headers
    )
    
    return results_response.json()

# Run analysis
results = upload_and_analyze("satellite_image.tif")
print("✓ Analysis complete!")
print(f"Results URL: {results['download_url']}")
// JavaScript: Upload satellite image and run analysis
const API_KEY = "your_api_key_here";
const BASE_URL = "https://api.greenspaceai.com/v1";

async function uploadAndAnalyze(imageFile, analysisType = "landcover") {
    // Step 1: Upload image
    const headers = {
        'Authorization': `Bearer ${API_KEY}`
    };
    
    const formData = new FormData();
    formData.append('file', imageFile);
    
    const uploadResponse = await fetch(`${BASE_URL}/upload`, {
        method: 'POST',
        headers: headers,
        body: formData
    });
    
    if (!uploadResponse.ok) {
        throw new Error(`Upload failed: ${await uploadResponse.text()}`);
    }
    
    const uploadData = await uploadResponse.json();
    const fileId = uploadData.file_id;
    console.log(`✓ Upload successful. File ID: ${fileId}`);
    
    // Step 2: Start analysis
    const analysisPayload = {
        file_id: fileId,
        analysis_type: analysisType,
        parameters: {
            model: "unet_plus",
            detail_level: "balanced"
        }
    };
    
    const analysisResponse = await fetch(`${BASE_URL}/analysis`, {
        method: 'POST',
        headers: {
            ...headers,
            'Content-Type': 'application/json'
        },
        body: JSON.stringify(analysisPayload)
    });
    
    const analysisData = await analysisResponse.json();
    const analysisId = analysisData.analysis_id;
    console.log(`✓ Analysis started. Analysis ID: ${analysisId}`);
    
    // Step 3: Poll for results
    while (true) {
        const statusResponse = await fetch(
            `${BASE_URL}/analysis/${analysisId}/status`,
            { headers }
        );
        
        const statusData = await statusResponse.json();
        const status = statusData.status;
        const progress = statusData.progress || 0;
        
        console.log(`Progress: ${progress}% - Status: ${status}`);
        
        if (status === "completed") {
            break;
        } else if (status === "failed") {
            throw new Error("Analysis failed");
        }
        
        await new Promise(resolve => setTimeout(resolve, 10000)); // Wait 10 seconds
    }
    
    // Step 4: Get results
    const resultsResponse = await fetch(
        `${BASE_URL}/analysis/${analysisId}/results`,
        { headers }
    );
    
    return await resultsResponse.json();
}

// Node.js: Upload satellite image and run analysis
const axios = require('axios');
const fs = require('fs');
const FormData = require('form-data');

const API_KEY = 'your_api_key_here';
const BASE_URL = 'https://api.greenspaceai.com/v1';

async function uploadAndAnalyze(imagePath, analysisType = 'landcover') {
    // Step 1: Upload image
    const formData = new FormData();
    formData.append('file', fs.createReadStream(imagePath));
    
    const uploadResponse = await axios.post(`${BASE_URL}/upload`, formData, {
        headers: {
            ...formData.getHeaders(),
            'Authorization': `Bearer ${API_KEY}`
        }
    });
    
    const fileId = uploadResponse.data.file_id;
    console.log(`✓ Upload successful. File ID: ${fileId}`);
    
    // Step 2: Start analysis
    const analysisPayload = {
        file_id: fileId,
        analysis_type: analysisType,
        parameters: {
            model: 'unet_plus',
            detail_level: 'balanced'
        }
    };
    
    const analysisResponse = await axios.post(`${BASE_URL}/analysis`, analysisPayload, {
        headers: {
            'Authorization': `Bearer ${API_KEY}`,
            'Content-Type': 'application/json'
        }
    });
    
    const analysisId = analysisResponse.data.analysis_id;
    console.log(`✓ Analysis started. Analysis ID: ${analysisId}`);
    
    // Step 3: Poll for results
    while (true) {
        const statusResponse = await axios.get(
            `${BASE_URL}/analysis/${analysisId}/status`,
            {
                headers: {
                    'Authorization': `Bearer ${API_KEY}`
                }
            }
        );
        
        const status = statusResponse.data.status;
        const progress = statusResponse.data.progress || 0;
        
        console.log(`Progress: ${progress}% - Status: ${status}`);
        
        if (status === 'completed') {
            break;
        } else if (status === 'failed') {
            throw new Error('Analysis failed');
        }
        
        await new Promise(resolve => setTimeout(resolve, 10000));
    }
    
    // Step 4: Get results
    const resultsResponse = await axios.get(
        `${BASE_URL}/analysis/${analysisId}/results`,
        {
            headers: {
                'Authorization': `Bearer ${API_KEY}`
            }
        }
    );
    
    return resultsResponse.data;
}

// Java: Upload satellite image and run analysis
import java.net.http.*;
import java.net.URI;
import java.nio.file.Path;
import java.util.concurrent.TimeUnit;
import com.fasterxml.jackson.databind.ObjectMapper;

public class GreenSpaceAI {
    private static final String API_KEY = "your_api_key_here";
    private static final String BASE_URL = "https://api.greenspaceai.com/v1";
    private static final ObjectMapper mapper = new ObjectMapper();
    
    public static Map<String, Object> uploadAndAnalyze(Path imagePath, String analysisType) 
            throws Exception {
        
        HttpClient client = HttpClient.newHttpClient();
        
        // Step 1: Upload image
        HttpRequest uploadRequest = HttpRequest.newBuilder()
                .uri(URI.create(BASE_URL + "/upload"))
                .header("Authorization", "Bearer " + API_KEY)
                .POST(HttpRequest.BodyPublishers.ofFile(imagePath))
                .build();
        
        HttpResponse<String> uploadResponse = client.send(uploadRequest, 
                HttpResponse.BodyHandlers.ofString());
        
        if (uploadResponse.statusCode() != 200) {
            throw new RuntimeException("Upload failed: " + uploadResponse.body());
        }
        
        Map<String, Object> uploadData = mapper.readValue(uploadResponse.body(), Map.class);
        String fileId = (String) uploadData.get("file_id");
        System.out.println("✓ Upload successful. File ID: " + fileId);
        
        // Step 2: Start analysis
        Map<String, Object> analysisPayload = new HashMap<>();
        analysisPayload.put("file_id", fileId);
        analysisPayload.put("analysis_type", analysisType);
        
        Map<String, Object> parameters = new HashMap<>();
        parameters.put("model", "unet_plus");
        parameters.put("detail_level", "balanced");
        analysisPayload.put("parameters", parameters);
        
        String analysisPayloadJson = mapper.writeValueAsString(analysisPayload);
        
        HttpRequest analysisRequest = HttpRequest.newBuilder()
                .uri(URI.create(BASE_URL + "/analysis"))
                .header("Authorization", "Bearer " + API_KEY)
                .header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString(analysisPayloadJson))
                .build();
        
        HttpResponse<String> analysisResponse = client.send(analysisRequest,
                HttpResponse.BodyHandlers.ofString());
        
        Map<String, Object> analysisData = mapper.readValue(analysisResponse.body(), Map.class);
        String analysisId = (String) analysisData.get("analysis_id");
        System.out.println("✓ Analysis started. Analysis ID: " + analysisId);
        
        // Step 3: Poll for results
        while (true) {
            HttpRequest statusRequest = HttpRequest.newBuilder()
                    .uri(URI.create(BASE_URL + "/analysis/" + analysisId + "/status"))
                    .header("Authorization", "Bearer " + API_KEY)
                    .GET()
                    .build();
            
            HttpResponse<String> statusResponse = client.send(statusRequest,
                    HttpResponse.BodyHandlers.ofString());
            
            Map<String, Object> statusData = mapper.readValue(statusResponse.body(), Map.class);
            String status = (String) statusData.get("status");
            Integer progress = (Integer) statusData.getOrDefault("progress", 0);
            
            System.out.println("Progress: " + progress + "% - Status: " + status);
            
            if ("completed".equals(status)) {
                break;
            } else if ("failed".equals(status)) {
                throw new RuntimeException("Analysis failed");
            }
            
            TimeUnit.SECONDS.sleep(10);
        }
        
        // Step 4: Get results
        HttpRequest resultsRequest = HttpRequest.newBuilder()
                .uri(URI.create(BASE_URL + "/analysis/" + analysisId + "/results"))
                .header("Authorization", "Bearer " + API_KEY)
                .GET()
                .build();
        
        HttpResponse<String> resultsResponse = client.send(resultsRequest,
                HttpResponse.BodyHandlers.ofString());
        
        return mapper.readValue(resultsResponse.body(), Map.class);
    }
}

Rate Limit Headers

Every API response includes rate limit headers to help you manage your usage:

X-RateLimit-Limit: 100 Maximum requests per day
X-RateLimit-Remaining: 87 Requests remaining today
X-RateLimit-Reset: 1705276800 Unix timestamp when limits reset
Retry-After: 60 Seconds to wait after hitting limits

Webhooks & Event Notifications

Setting Up Webhooks

Webhooks allow you to receive real-time notifications when events occur in the GreenSpace AI platform.

Available Events

  • analysis.completed - Analysis finished processing
  • analysis.failed - Analysis failed
  • export.ready - Export file ready for download
  • model.trained - Custom model training completed
  • quota.warning - Approaching rate limit

Webhook Configuration

curl -X POST \
-H "Authorization: Bearer API_KEY" \
-d '{
  "url": "https://your-app.com/webhooks",
  "events": ["analysis.completed"],
  "secret": "your_webhook_secret"
}' \
https://api.greenspaceai.com/v1/webhooks

Webhook Security

All webhook payloads are signed with HMAC-SHA256. Verify signatures using your webhook secret to ensure the request originated from GreenSpace AI.

API Best Practices

Implement Retry Logic

Use exponential backoff with jitter for retrying failed requests. Handle rate limit errors (429) and server errors (5xx) gracefully.

Cache Results

Cache analysis results locally to avoid repeated API calls for the same data. Implement proper cache invalidation strategies.

Monitor Usage

Track API usage and implement alerts for approaching rate limits. Use the rate limit headers to optimize request timing.

Secure API Keys

Never expose API keys in client-side code. Use environment variables or secure key management services in production.
