Authentication

All API requests require authentication using a Bearer token. You can generate your API key from the dashboard after registration.

Get Your API Key

Register for an account and navigate to Dashboard → API Settings to generate your key.

gsai_sk_test_51NabcDefGhiJklMnoPqrStuVwxYz1234567890

Using the API Key

Include the API key in the Authorization header of all requests:

Authorization: Bearer your_api_key_here
POST /auth/token
Generate a new access token using your API credentials.

Request Body

Parameter Type Required Description
api_key string Yes Your API key
expires_in integer No Token expiry in seconds (default: 3600)

Response

{
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "token_type": "bearer",
  "expires_in": 3600,
  "scope": "read write"
}

Rate Limiting

API requests are limited based on your subscription plan:

  • Free Tier: 100 requests/month
  • Professional: 10,000 requests/month
  • Enterprise: Unlimited requests

Rate limit headers are included in all responses:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1689876543

Analysis Endpoints

POST /analyze
Submit an image for green space segmentation and temperature analysis.

Parameters

Parameter Type Required Description
image file Yes Satellite image file (TIFF, JPEG, PNG)
model string No Segmentation model: 'unet' (default), 'deeplab', 'custom'
include_temperature boolean No Include temperature analysis (default: true)
region string No Geographic region for better accuracy

Try This Endpoint

Test the analysis endpoint with a sample image:

Analysis submitted successfully! Job ID: analysis_12345

Response Example

{
  "job_id": "analysis_1234567890",
  "status": "processing",
  "estimated_time": 45,
  "webhook_url": "https://api.greenspaceai.com/v1/webhook/status",
  "created_at": "2024-06-15T10:30:00Z"
}

Results Endpoints

GET /results/{result_id}/download
Download analysis results in various formats.

Query Parameters

Parameter Type Required Description
format string Yes Output format: 'pdf', 'geotiff', 'geojson', 'png'
resolution string No Image resolution: 'low', 'medium', 'high'

Error Handling

The API uses standard HTTP status codes and returns detailed error messages in JSON format.

Error Response Format

{
  "error": {
    "code": "invalid_api_key",
    "message": "The provided API key is invalid or has expired.",
    "details": "Please generate a new API key from your dashboard.",
    "documentation_url": "https://docs.greenspaceai.com/api/authentication"
  }
}

Common Error Codes

Status Code Error Code Description
400 invalid_request Malformed request or invalid parameters
401 invalid_api_key Invalid or missing API key
404 not_found Resource not found
500 server_error Internal server error
