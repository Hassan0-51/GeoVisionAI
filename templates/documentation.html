GreenSpace AI Documentation v1.0.0

Comprehensive guide to using the GreenSpace AI platform for urban green space analysis.

Getting Started

Welcome to GreenSpace AI! This platform allows you to analyze urban green spaces using satellite imagery and deep learning. Follow these steps to begin:

1

Create an Account

Register for a free account to get started with basic features. Academic users may qualify for extended limits.

2

Choose Your Plan

Select between Free, Professional, or Enterprise plans based on your needs. Free tier includes 5 analyses per month.

3

Upload Your First Image

Upload satellite imagery (Sentinel-2, Landsat, or custom) through our web interface or API.

Tip: For best results, use cloud-free satellite imagery with at least 10m resolution.

Image Upload Guidelines

Supported Formats

  • GeoTIFF (.tif, .tiff) - Preferred format with geospatial metadata
  • JPEG (.jpg, .jpeg) - Standard image format
  • PNG (.png) - Lossless compression
  • Sentinel-2 SAFE format - Direct upload from ESA

Image Requirements

Parameter Minimum Recommended
Resolution 10m/pixel 2.5m/pixel
Cloud Cover < 30% < 10%
Image Size 512×512 px 2048×2048 px
File Size 1 MB < 100 MB

Coordinate Systems

For accurate geospatial analysis, ensure your images include coordinate reference system (CRS) information. Supported CRS:

  • WGS 84 (EPSG:4326)
  • UTM Zone 43N (EPSG:32643) - For Lahore region
  • Web Mercator (EPSG:3857)

Image Segmentation

Our platform uses deep learning models to segment satellite imagery into different land cover classes.

Available Models

U-Net Default

High accuracy for general green space segmentation. Best for urban areas.

  • Accuracy: 92%
  • Inference Time: 15s
  • Training Data: 10k images

DeepLabv3+

Better for complex urban landscapes with mixed vegetation.

  • Accuracy: 94%
  • Inference Time: 20s
  • Training Data: 15k images

Custom Model

Enterprise users can train custom models on specific datasets.

  • Accuracy: Custom
  • Inference Time: Varies
  • Training Data: Your dataset

Segmentation Classes

The models identify the following land cover classes:

  • Green Vegetation - Trees, grass, crops
  • Built-up Areas - Buildings, roads
  • Water Bodies - Rivers, lakes, ponds
  • Bare Soil - Exposed land, construction sites
  • Other Vegetation - Shrubs, seasonal crops

API Reference

Integrate GreenSpace AI with your applications using our REST API.

API Base URL: https://api.greenspaceai.com/v1

Authentication

All API requests require an API key in the header:

Authorization: Bearer your_api_key_here

Endpoints

POST
/analyze - Analyze an image

Submit an image for segmentation and analysis.

# Example request
curl -X POST \
-H "Authorization: Bearer YOUR_API_KEY" \
-F "image=@path/to/image.tif" \
-F "model=unet" \
https://api.greenspaceai.com/v1/analyze
GET
/results/{job_id} - Get analysis results

Retrieve results for a completed analysis job.

GET
/user/usage - Get usage statistics

Check your current API usage and limits.

Note: Free tier API is limited to 100 requests per month. Upgrade to Professional for higher limits.

Frequently Asked Questions

General Questions

How accurate is the green space segmentation?

Our models achieve 92-94% accuracy on urban green spaces, validated against ground truth data from Lahore.

Can I use the platform for commercial purposes?

Yes, the Professional and Enterprise plans allow commercial use. Free tier is for academic/research purposes only.

Technical Questions

How long does analysis take?

Typical analysis time is 30-60 seconds for a 1km² area, depending on server load and image complexity.

What's the maximum image size?

Web interface: 100MB per image. API: 500MB for Enterprise users.

Can I analyze temporal changes?

Yes, Professional and Enterprise users can upload time-series data and track changes over time.
