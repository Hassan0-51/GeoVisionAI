GIS Export Formats Overview

GreenSpace AI supports comprehensive GIS export capabilities, allowing you to transfer analysis results seamlessly into your preferred GIS software for further analysis, visualization, and integration with existing spatial datasets.

Shapefile (.shp)

Industry-standard vector format compatible with ArcGIS, QGIS, and most GIS software. Includes required supporting files (.shx, .dbf, .prj).

ArcGIS QGIS Multi-part

GeoJSON (.geojson)

Web-friendly format ideal for web mapping applications, JavaScript libraries, and modern GIS workflows. Human-readable JSON structure.

Web Mapping JavaScript Leaflet/Mapbox

KML/KMZ (.kml/.kmz)

Google Earth compatible format with built-in styling and visualization. KMZ format includes compressed files with embedded resources.

Google Earth 3D Visualization Style Included

GeoTIFF (.tif)

Raster format with embedded georeferencing information. Perfect for classification results, confidence layers, and continuous data.

Raster Data Multi-band Compression

CSV with WKT (.csv)

Tabular data with Well-Known Text (WKT) geometry representation. Ideal for statistical analysis, data science workflows, and database imports.

Excel Python/R Database

PostGIS/Spatialite

Direct export to spatial databases. Includes SQL scripts for table creation and data import with spatial indexing.

PostgreSQL SQLite Spatial DB

Quick Import Scripts

# Python: Import GreenSpace AI exports
import geopandas as gpd
import rasterio
import json

# Method 1: Read Shapefile
def read_shapefile(file_path):
    gdf = gpd.read_file(file_path)
    print(f"CRS: {gdf.crs}")
    print(f"Features: {len(gdf)}")
    print(f"Columns: {gdf.columns.tolist()}")
    return gdf

# Method 2: Read GeoJSON
def read_geojson(file_path):
    with open(file_path, 'r') as f:
        data = json.load(f)
    gdf = gpd.GeoDataFrame.from_features(data['features'])
    return gdf

# Method 3: Read GeoTIFF
def read_geotiff(file_path):
    with rasterio.open(file_path) as src:
        data = src.read()
        profile = src.profile
        bounds = src.bounds
    return data, profile, bounds

# Usage example
if __name__ == "__main__":
    # Read classification results
    results = read_shapefile("greenspace_export.shp")
    
    # Calculate area by class
    area_by_class = results.groupby('class_name')['geometry'].area.sum()
    print("\nArea by land cover class:")
    print(area_by_class)

// JavaScript: Import GreenSpace AI exports for web mapping
import * as L from 'leaflet';

// Method 1: Load GeoJSON for Leaflet
async function loadGeoJSON(filePath) {
    const response = await fetch(filePath);
    const geojson = await response.json();
    
    // Create Leaflet layer with styling
    const geojsonLayer = L.geoJSON(geojson, {
        style: function(feature) {
            const className = feature.properties.class_name;
            return {
                fillColor: getColorForClass(className),
                weight: 1,
                opacity: 1,
                color: 'white',
                fillOpacity: 0.7
            };
        },
        onEachFeature: function(feature, layer) {
            const props = feature.properties;
            const popupContent = `
                <strong>${props.class_name}</strong><br>
                Area: ${props.area.toFixed(2)} km²<br>
                Confidence: ${props.confidence}%
            `;
            layer.bindPopup(popupContent);
        }
    });
    
    return geojsonLayer;
}

// Helper function for class colors
function getColorForClass(className) {
    const colors = {
        'Urban': '#ff5722',
        'Vegetation': '#4caf50',
        'Water': '#2196f3',
        'Bare Soil': '#795548'
    };
    return colors[className] || '#cccccc';
}

Python Batch Export Script

# Python: Batch export multiple analyses
import requests
import time
import zipfile
import os

API_KEY = "your_api_key_here"
BASE_URL = "https://api.greenspaceai.com/v1"

def batch_export_analyses(analysis_ids, export_formats=["shapefile", "geojson"]):
    headers = {"Authorization": f"Bearer {API_KEY}"}
    
    export_jobs = []
    
    # Create export jobs for each analysis
    for analysis_id in analysis_ids:
        export_payload = {
            "analysis_id": analysis_id,
            "formats": export_formats,
            "include_metadata": True,
            "crs": "EPSG:4326",
            "compression": "zip"
        }
        
        response = requests.post(
            f"{BASE_URL}/export",
            headers=headers,
            json=export_payload
        )
        
        if response.status_code == 202:
            job_id = response.json()['job_id']
            export_jobs.append({"analysis_id": analysis_id, "job_id": job_id})
            print(f"✓ Export queued for analysis {analysis_id}")
        else:
            print(f"✗ Failed to queue export for {analysis_id}")
    
    # Monitor job progress
    completed_jobs = []
    while export_jobs:
        for job in export_jobs[:]:
            status_response = requests.get(
                f"{BASE_URL}/export/{job['job_id']}/status",
                headers=headers
            )
            
            status = status_response.json()['status']
            
            if status == "completed":
                download_url = status_response.json()['download_url']
                job['download_url'] = download_url
                completed_jobs.append(job)
                export_jobs.remove(job)
                print(f"✓ Export completed for analysis {job['analysis_id']}")
            elif status == "failed":
                print(f"✗ Export failed for analysis {job['analysis_id']}")
                export_jobs.remove(job)
        
        if export_jobs:
            print(f"Waiting for {len(export_jobs)} exports...")
            time.sleep(5)
    
    # Download all exports
    for job in completed_jobs:
        download_response = requests.get(job['download_url'])
        
        with open(f"exports/analysis_{job['analysis_id']}.zip", 'wb') as f:
            f.write(download_response.content)
        
        # Extract and organize
        with zipfile.ZipFile(f"exports/analysis_{job['analysis_id']}.zip", 'r') as zip_ref:
            extract_path = f"exports/analysis_{job['analysis_id']}"
            zip_ref.extractall(extract_path)
    
    print("✓ All exports downloaded and extracted!")
    return completed_jobs

# Example usage
analysis_ids = ["analysis_123", "analysis_456", "analysis_789"]
batch_export_analyses(analysis_ids)

Common Issues & Troubleshooting

Missing Projection Files

Symptoms: GIS software shows "Unknown CRS" or incorrect coordinates.

Solution:
  • Re-export with "Include PRJ file" option
  • Manually assign CRS in your GIS software
  • Use WGS84 (EPSG:4326) for web applications

Large File Size

Symptoms: Export takes too long or fails due to size limits.

Solution:
  • Use compression (ZIP or 7Z)
  • Export only necessary layers
  • Split large areas into tiles

Attribute Data Issues

Symptoms: Missing fields or incorrect data types in exported files.

Solution:
  • Check "Include Metadata" option
  • Use CSV format for complex attributes
  • Validate field names (avoid special characters)

Export Validation Checklist

Before Export

  • Verify analysis completion status
  • Check available storage space
  • Confirm required export formats
  • Set appropriate coordinate system

After Export

  • Verify file integrity (no corruption)
  • Check CRS assignment in GIS software
  • Validate attribute table completeness
  • Test layer visualization

Integration Testing

  • Import into target GIS software
  • Verify styling and symbology
  • Test overlay with other datasets
  • Validate coordinate alignment

API Export Integration

REST API Endpoints

POST /v1/export
Create a new export job for an analysis. Returns job ID and status URL.
GET /v1/export/{job_id}/status
Check export job status. Returns progress percentage and download URL when complete.
GET /v1/export/formats
List available export formats and their capabilities.
DELETE /v1/export/{job_id}
Cancel an export job. Only works for jobs that haven't started processing.
